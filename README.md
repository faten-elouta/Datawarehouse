# Datawarehouse — Modélisation OLAP multi-sources

Projet académique de conception d'un entrepôt de données à partir de trois jeux de données hétérogènes : Covid19Canada, Covid19France et policier-shooting (fusillades impliquant la police aux États-Unis).

## Objectif

Démontrer l'opérateur intentionnel OLAP « Assess » en proposant, pour chaque source, un modèle conceptuel au format DFM (Dimensional Fact Model).

## Contenu du dépôt

Le fichier `Data warehouse.pptx` présente le modèle conceptuel (DFM) pour chaque jeu de données. Les archives `Covid19Canada-master.zip`, `covid-France.zip` et `policier_bundle_archive.zip` contiennent les données brutes correspondantes.

## Utilisation

Consulter `Data warehouse.pptx` pour le modèle conceptuel, puis décompresser les archives correspondantes pour explorer les données sources.

## Contexte

Projet réalisé en binôme dans un cadre académique.
